# 硬件资源与来源

本公开工程只提供原厂资源链接，不再分发原厂 PDF、板级 STEP、尺寸图或带商家水印的商品照片。原厂资料自身的许可与适用版本以来源为准。

- [微雪 V1 原理图](https://files.waveshare.com/wiki/ESP32-S3-Touch-AMOLED-1.8/ESP32-S3-Touch-AMOLED-1.8.pdf)
- [微雪 V1 资源页](https://docs.waveshare.com/ESP32-S3-Touch-AMOLED-1.8/Resources-And-Documents)
- [微雪板级 STEP 资源](https://files.waveshare.com/wiki/ESP32-S3-Touch-AMOLED-1.8/ESP32-S3-Touch-AMOLED-1.8-3D.zip)
- [Sensirion SCD4x 产品与文档](https://sensirion.com/products/catalog/SCD41)
- [SFA40 原厂数据手册](https://sensirion.com/media/documents/5B06EDD9/69F84BD8/Sensirion_Datasheet_SFA40.pdf)
- [SFA40 结构集成指南](https://sensirion.com/media/documents/851ABA76/6A38E89C/DesignIn_Guide_SFA40.pdf)

以 TP 编号、模块丝印和实际转接板电路确认接线。芯片手册不能替代转接板的电源、电平、上拉和尺寸信息；官方板级 STEP 也不等于原塑料外壳的实测装配模型。

本项目使用的 SCD41 转接板平面尺寸为 21.6×13.4 mm。SFA40 模块及焊线总包络、原壳止口和螺钉均应按实物核对。接线步骤见[使用说明](../接线与刷写说明.md)，结构假设见 [AirDock 60](../enclosure/airdock-60/README.md)。
